# Widgets App

## Descripción / Description

**Widgets App** es una aplicación desarrollada en **Flutter** que implementa los principales **widgets de Flutter**, sirviendo como una guía práctica para comprender su uso, comportamiento y personalización dentro de una aplicación móvil.

**Widgets App** is a Flutter application that implements the main **Flutter widgets**, serving as a practical guide to understand their usage, behavior, and customization within a mobile application.

---

## Tecnologías y librerías / Technologies and Libraries

- Flutter
- Dart
- go_router
- animated_do
